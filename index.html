A small proxy you deploy yourself, which holds the execution credential server-side and applies its own rate limits — proxy/ in the repository, with a Cloudflare Worker entry and a Node one. Leave it empty to run nothing but JavaScript unless a local runner is up. Nothing is ever sent to a local address unless the toolbar says Local.

Advanced setup

Use the address 127.0.0.1 rather than the name localhost: browsers exempt loopback addresses from mixed-content blocking so this page can reach them over plain HTTP, but Firefox does not extend that to the name.

The runner writes a fresh token on every start and the page picks it up from the repository folder. Paste it here only when the site is served from somewhere that file is not — the published page, for instance.

Under Docker instead, if you would rather not use WSL: 

docker compose -f judge/compose.yml up -d

A default hosted address can be baked into data/config.json so the published site has one without anybody typing it in. The address above overrides it for this browser.
