How it goes

  1. 1

    Pick something

    Filter by topic, difficulty or what you have not finished — or open the track you are on and take the next node in it.

  2. 2

    Answer it properly

    An expression is parsed and compared as mathematics, not matched as a string. A program is compiled and run against real cases, and the sanitizer has to be quiet when the problem says so.

  3. 3

    Find out why

    Wrong answers come with the reason, the case that broke it, and the reading that covers it. The solution unlocks when you have earned it or decided to look.

What you get for it

It runs in the tab

C++ compiles in the browser, on a real Clang built to WebAssembly, and Python runs on a real CPython built the same way. So does Rust — a real rustc, with the real borrow checker. Anything graded by a sanitizer needs a runner you start yourself, or a small proxy you deploy, and the bar under the editor always names which one answered.

Marking that can be argued with

Bad syntax is told apart from a wrong answer. A failing case shows the input, what was expected and what came out. Nothing is certified correct because it looked right at a few sampled points.

A record you own

Solves, drafts, submissions, XP and a year of activity, all in this browser. Export it as JSON to carry it somewhere else, or to hand it to the Learning Tree tracker.

Not configured

A small proxy you deploy yourself, which holds the execution credential server-side and applies its own rate limits — proxy/ in the repository, with a Cloudflare Worker entry and a Node one. Leave it empty to run nothing but JavaScript unless a local runner is up. Nothing is ever sent to a local address unless the toolbar says Local.

Advanced setup

Use the address 127.0.0.1 rather than the name localhost: browsers exempt loopback addresses from mixed-content blocking so this page can reach them over plain HTTP, but Firefox does not extend that to the name.

The runner writes a fresh token on every start and the page picks it up from the repository folder. Paste it here only when the site is served from somewhere that file is not — the published page, for instance.

Under Docker instead, if you would rather not use WSL: 

docker compose -f judge/compose.yml up -d

A default hosted address can be baked into data/config.json so the published site has one without anybody typing it in. The address above overrides it for this browser.
